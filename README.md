# 棱版 Prism Plate

Go 二维打样渲染服务。HTTP 接收不可变稿本，输出具有内容摘要的 PNG 和 SVG，支持有界异步成像、校样裁决与可移交版面封包。领域为图形渲染，产品形态为 backend；依赖只有 Go 标准库。

## 启动

需要 Go 1.24 或更新版本；本次验证环境为 Go 1.27.0 / macOS arm64。演示流程还需要 Python 3 标准库。构建和运行无需网络。

```sh
go build -o bin/prismplate ./cmd/prismplate
./bin/prismplate -listen 127.0.0.1:7846 -data var/prism-plate-v1
```

```sh
curl -H 'Content-Type: application/json' --data-binary @examples/amber-proof.json http://127.0.0.1:7846/v1/plates
curl -X POST 'http://127.0.0.1:7846/v1/plates/amber-plate/render?revision=1&format=png'
```

第二个响应返回成品 id；以 GET /v1/artifacts/{id} 获取图片。服务不依赖浏览器、GPU、机器字体、联网字体服务或外部图片；文字只使用随项目上传的字体。默认只监听回环地址，无身份认证；运行边界和容器挂载见 docs/operations.md。

## 场景约定

examples/amber-proof.json 提供曲线、线性渐变、仿射变换、镂空、裁域、二值蒙版和 screen 叠色。坐标原点在左上，颜色为 0..1 的 sRGB 直通色值，PNG 在内部转换为线性光预乘透明度。M/L/Q/C/Z 路径必须显式闭合，轮廓至少三条端点指令；Q/C 分别固定细分16/24段。图层可选 normal/multiply/screen，组透明度在整层合成后施加，蒙版与裁域处于版面坐标，笔刷与填充轮廓处于形状局部坐标。未提供的数值使用 JSON 的零值；形状必须明确传入可逆 transform。

## 文字对象与字体

图层可含 texts 数组，每个文字对象是可编辑的文本节点：稿本只保存 source 原文、font 字体标识、可选 font_digest 摘要钉、size、origin（基线起点）、letter_spacing、brush 与可逆 transform；轮廓在编译准入时从上传的字体字节确定性展开，渲染与恢复共用同一展开路径。编辑文字即提交新稿本，旧稿本不变。

排版范围（有界子集，超出即拒绝而非降级）：水平单行、自左向右；每个 Unicode 码位经 cmap（format 4/12）映射一个字形；跨字形间距来自 hmtx 步进与 kern 表（format 0）字对，letter_spacing 加在每个字形步进之后（含末尾）；不支持复杂塑形、合字、双向、竖排与变体选择子。缺失字形在准入时报 400，错误文本给出文字节点 id、码位（U+XXXX）与字符序号，可定位缺口。字形轮廓按嵌套奇偶归一方向后以 nonzero 填充，轮廓内孔不依赖字体自身的环绕方向；文字在局部坐标展开后由 transform 施加旋转缩放，与形状共用同一仿射路径，旋转缩放稳定。

字体经 POST /v1/fonts 上传，只接受 TrueType glyf 轮廓（拒绝 CFF/OTTO、位图与可变字体），单字体不超过 2MiB，每数据根最多 32 个。字体不可改写、不可删除：同一标识永远不能重新绑定到不同字节，因此文字引用在任何接受该字体的服务上解析一致。上传时从 name 表提取 family 与 license 声明（nameID 13/14）作为来源记录；许可合规性由上传方负责，服务记录声明而不做法律核验。scripts/make_demo_font.py 生成一个确定性的 OFL 演示字体（示意轮廓，含字距对、复合字形与 CJK 码位），供流程验证使用。

字体携带而非轮廓固化：封包（schema prism-plate-bundle-v2）携带版面引用的全部字体字节并逐字体校验摘要，接收方导入后以相同字体字节重新展开文字，PNG/SVG 成品摘要与来源服务逐字节一致，不因机器字体差异而排版漂移；同一字体标识若已绑定不同摘要，整个封包拒绝导入。选择携带而非固化的理由：稿本只存文字来源与字体引用这一份事实，接收方保持可编辑性；固化会把展开几何复制进每个稿本、放大摘要面，且接收方没有相同字体时反而无法继续编辑。SVG 输出同样只含展开轮廓，不含 text 元素或字体引用。

PNG 是像素校样的权威结果：每像素四点覆盖采样，画布最大512×512。SVG 是复用展开几何的矢量校样；浏览器在覆盖率与透明渐变插值方面可能产生差异，不承诺逐像素相同。所有数值和引用均由服务生成，SVG不接受任意标记、脚本或外链。

## 版本及生命周期

新建版面的初始稿本为1。PUT 传 expected_revision，只有当前最新版本相符才追加；旧版本不修改。归档禁止后续修订，仍可渲染历史及从历史分支。异步任务提交即捕获指定稿本；稍后修订不会改变它。任务只在当前进程内保留，重启后以已持久化成品为事实，不支持任务续跑；256条任务记录用尽后拒绝新任务。两名工作者、8条等待队列，所有渲染共用2个计算名额，同步或异步均可能在拥挤时得到拒绝。

取消是请求，已进入成品提交点的任务仍可成功；成功任务的事实不会变为取消。取消或失败不得提交半张图片。成品按版面、稿本、格式、内容摘要产生稳定标识；撤销后不允许再次悄悄激活。校样只有 open→accepted/rejected；通过的校样禁止撤销其成品。

## 入口

详见 docs/api.md。保存版面、修订、分支、归档、PNG、SVG、异步提交、取消、成品读取/撤销、校样、封包、恢复及写入隔离分别有独立的有界生产流程：

```sh
python3 scripts/walkthrough.py --workflow png
python3 scripts/walkthrough.py --workflow bundle
```

可选workflow值：create、revise、branch、archive、png、svg、exposure、cancel、artifact、proof、bundle、restore、isolation、rejection、text、textbundle。每个流程在临时数据根启动实际HTTP服务，完成后正常关停，不占用长期端口、不修改演示输入。text 流程验证字体上传/拒绝、字距与 kerning 定位、内孔像素、旋转缩放、缺失字形定位与文字修订；textbundle 流程验证封包携带字体、摘要篡改拒绝、导入去重与跨服务渲染零漂移。

## 持久化与范围

完整状态以临时写入、文件fsync、原子替换提交，失败写入不会成为内存事实。数据根使用排他 writer.lock；干净退出会清除，异常退出后需人工确认没有旧进程再清除。摘要校验保护谱系一致性，不提供恶意篡改认证。启动还会重新解析持久化字体并重新编译持久化场景。封包含版面稿本与其引用的字体，不含成品、校样和任务；导入重名拒绝，不合并历史；字体按摘要去重，同标识不同摘要整包拒绝。

上线容量：128版面，每版64稿本，256成品，1024校样，32字体（每个≤2MiB），状态快照128MiB，HTTP输入8MiB，单稿本4倍采样预计边遍历不超过1.6亿。容量达到时需要运维规划，不会自动淘汰被校样引用的数据。完整快照复制意味着吞吐适用于小规模打样服务。

自动化测试套件按初始化边界延后，本仓库不含测试命令。已提供构建、静态检查与真实生产流程演示；后续质量保障任务可以建立独立测试体系。Dockerfile提供容器构建路径，容器跨架构和生产部署不在本机Go构建的验证结论内。
